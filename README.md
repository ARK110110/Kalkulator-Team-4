# Kalkulator-Team-4
Website Kalkulator

Project Website

Project ini dibuat menggunakan HTML, Tailwind CSS, JavaScript, dan Backend. HTML digunakan untuk membangun struktur halaman, Tailwind CSS untuk mempercantik dan membuat tampilan lebih responsif, JavaScript untuk menambahkan interaksi, sedangkan backend digunakan untuk mengelola proses dan data pada website.

Project ini dibuat sebagai media pembelajaran sekaligus untuk mengembangkan kemampuan dalam membuat aplikasi web yang menggabungkan frontend dan backend. Tampilan dan fitur di dalamnya masih dapat dikembangkan lagi sesuai kebutuhan.
